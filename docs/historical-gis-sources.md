# 历史 GIS 边界数据说明

## 已采用

本项目采用 `historical-basemaps` 的 GeoJSON 作为历史边界层。该项目提供 WGS84 / EPSG:4326 的历史边界 GeoJSON，并在字段中包含 `NAME`、`SUBJECTO`、`PARTOF`、`BORDERPRECISION`。本地页面把这些图层裁到中东、北非、巴尔干视野内。

| 页面层 | 目标年份 | 实际数据年份 | 文件 | 说明 |
|---|---:|---:|---|---|
| 1500 奥斯曼早期扩张 | 1453 | 1500 | world_1500.geojson | 用于补足君士坦丁堡陷落后的早期奥斯曼版图。它不是 1453 当年边界，而是用 1500 年数据近似展示奥斯曼早期扩张后的帝国核心。 |
| 1600 奥斯曼高峰 | 1526 | 1600 | world_1600.geojson | 用于展示 16 世纪奥斯曼高峰期的帝国空间。它不是 1526 当年边界，而是用 1600 年数据近似呈现巴尔干、安纳托利亚、埃及、两河和黎凡特同属帝国秩序的格局。 |
| 1878 柏林会议后 | 1878 | 1880 | world_1880.geojson | 数据集中没有 1878 年，采用 1880 年世界边界近似表示柏林会议后的格局。 |
| 1913 巴尔干战争后 | 1913 | 1914 | world_1914.geojson | 数据集中没有 1913 年，采用 1914 年世界边界近似表示巴尔干战争后的战前格局。 |
| 1920 委任统治/塞夫尔 | 1920 | 1920 | world_1920.geojson | 数据集中有 1920 年，用作圣雷莫、委任统治和塞夫尔方案时期的边界层。 |
| 1923 洛桑后 | 1923 | 1930 | world_1930.geojson | 数据集中没有 1923 年，采用 1930 年世界边界近似表示洛桑条约后相对稳定的格局。 |

## 查到但未采用为主图层

- CShapes 2.0：适合近现代独立国家和属地边界，覆盖 1886-2019；它适合后续补强 1913、1920、1923，但无法覆盖 1878。
- Euratlas：有欧洲历史政治边界矢量数据，但公开页面显示需要 Duke 机构访问/授权，不适合作为当前本地自动化下载源。

## 精度说明

1878、1913、1923 在当前开放数据集中没有同年文件，所以本地页面明确标注为邻近年份近似层。它们比现代边界底图更适合讲视频中的历史格局，但仍不应当作为学术级精确边界使用。
